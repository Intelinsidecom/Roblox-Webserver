# Games Page JavaScript Analysis - Data Loading Expectations

## Overview
The games page uses a sophisticated JavaScript architecture to load and display game entries dynamically. The system is built around several key components that work together to fetch, render, and manage game data.

## Core JavaScript Components

### 1. Main Entry Points
- **GamesPageContainerBehavior.js** - Main container behavior, handles filter changes and URL management
- **GamesListBehavior.js** - Handles individual game card interactions, carousels, and voting
- **gamesPage.js** - Core page logic, manages state, infinite scroll, and overall page behavior
- **gamesList.js** - Individual game list management, handles API calls and rendering

### 2. Supporting Components
- **search.js** - Search functionality and results handling
- **filters.js** - Filter management (sort, time, genre)
- **constants.js** - Configuration constants and enums
- **state.js** - Page state management
- **settings.js** - Page settings and configuration
- **VotingPanel.js** - Voting functionality for games

## API Request Parameters

### Game Loading Request (buildFetchRequest)
The JavaScript sends these parameters to load games:

```javascript
{
    SortFilter: number,           // Sort type (1=Popular, 8=Top Earning, etc.)
    TimeFilter: number,           // Time filter (0=Current, 1=Daily, 2=Weekly, 4=AllTime)
    RegionFilter: number,         // Region filter (183=Default)
    GenreID: number,              // Genre filter (1=All)
    GameFilter: number,           // Game filter (1=All, 0=User-specific)
    MinBCLevel: number,           // Minimum BC level (0=All)
    StartRows: number,            // Starting row for pagination
    MaxRows: number,              // Number of rows to fetch
    IsUserLoggedIn: boolean,      // User authentication status
    NumberOfRowsToOccupy: number, // Number of rows to occupy
    NumberOfColumns: number,      // Calculated number of columns
    IsInHorizontalScrollMode: boolean, // Horizontal scroll mode
    DeviceTypeId: number,         // Device type (1=Desktop)
    AdSpan: number,               // Ad span configuration
    AdAlignment: number,          // Ad alignment
    v: 2,                         // API version
    PersonalizedUniverseId: number, // Personalized universe ID
    useFakeResults: boolean,      // Use fake results for testing
    IsGamesThumbnailAsyncEnabled: boolean // Async thumbnail loading
}
```

### Search Request Parameters
For search functionality:

```javascript
{
    StartRows: number,           // Starting row
    MaxRows: number,              // Number of results
    IsUserLoggedIn: boolean,      // User authentication status
    NumberOfColumns: number,      // Calculated columns
    IsInHorizontalScrollMode: boolean, // Horizontal scroll mode
    DeviceTypeId: number,         // Device type
    Keyword: string,              // Search query
    AdSpan: number,               // Ad span
    AdAlignment: number,          // Ad alignment
    v: 2,                         // API version
    IsSecure: boolean,            // Secure mode
    UseFakeResults: boolean,      // Use fake results
    SuggestedCorrection: string,  // Suggested correction
    SuggestionKeyword: string,    // Suggestion keyword
    SuggestionReplacedKeyword: string // Replaced keyword
}
```

## Key Features Expected

### 1. Infinite Scroll
- Automatically loads more games when user scrolls near bottom
- Uses `shouldLoadMoreGames()` to determine when to fetch

### 2. Multi-View Mode
- Can display multiple game lists simultaneously
- Switches between single and multi-view based on filter selection

### 3. Voting System
- Each game card can have upvote/downvote functionality
- Vote percentages calculated and displayed dynamically
- Requires user authentication for voting

### 4. Responsive Design
- Adapts layout based on screen size
- Calculates optimal number of columns dynamically
- Handles mobile vs desktop layouts

### 5. Search Integration
- Real-time search with suggestions
- Handles search corrections and suggestions
- Maintains search state in URL

### 6. Filter System
- Sort filters (Popular, Top Rated, etc.)
- Time filters (Current, Daily, Weekly, All Time)
- Genre filters
- Region filters

## Configuration Settings

### Key Settings from settings.js:
- `numGamesToFetchInVScrollMode: 60` - Games to fetch in vertical scroll
- `numGamesToFetchInHScrollMode: 14` - Games to fetch in horizontal scroll
- `maxNumGamesToFetchPerRequest: 200` - Maximum games per request
- `columnWidthIncludingPadding: 161` - Column width calculation
- `gameTileHeight: 235` - Game tile height
- `rowHeightIncludingPadding: 220` - Row height calculation

## API Endpoints
- `/games/moreresultscached` - For cached results (default sort filters)
- `/games/moreresultsuncached` - For uncached results (user-specific filters)
- `/voting/vote?assetId={id}&vote={true/false}` - Voting endpoint
- `/games/votingservice/{placeId}` - Voting service endpoint

## Error Handling
The system expects graceful handling of:
- Network failures during game loading
- Invalid API responses
- Missing voting data
- Authentication failures for voting
- Empty search results

## Performance Considerations
- Lazy loading of thumbnails
- Debounced resize and scroll handlers
- Efficient DOM manipulation
- Minimal reflows and repaints
- Proper event delegation

This analysis provides the complete data structure and API expectations for the games page JavaScript system.
